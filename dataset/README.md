# Datasets

Nine streams are used. All are numeric, one column per variable, one row per time step.

| Stream | File | T x N | Source |
|---|---|---|---|
| ETTh2 | `ETT-small/ETTh2.csv` | 17,420 x 7 | ETT benchmark |
| Weather | `weather/weather.csv` | 52,696 x 21 | Autoformer benchmark collection |
| Electricity | `electricity/electricity.csv.gz` | 26,304 x 321 | Autoformer benchmark collection |
| Exchange | `exchange_rate/exchange_rate.csv` | 7,588 x 8 | Autoformer benchmark collection |
| PEMS08 | `PEMS/PEMS08.npz` | 17,856 x 170 | Caltrans PeMS (traffic flow) |
| Traffic | `traffic/traffic.csv.gz` | 17,544 x 862 | Autoformer benchmark collection |
| Air-Stream | not included (114 MB); rebuild with `prepare_eac_streams.py` into `air_stream/air_stream.csv` | 34,065 x 1,087 | EAC (ICLR'25) AQI data, nodes present in all four yearly periods |
| Energy-Stream | `energy_stream/energy_stream.csv` | 34,560 x 103 | EAC (ICLR'25) wind-turbine nacelle temperature, nodes present in all periods |
| SCA-Stream-v2 | `sca_stream_v2/seed_00..04.npz`, `sca_stream_v2_csv/*.csv` | 16,384 x 20 | controlled graph-VAR stream generated by `generate_sca_stream_v2.py` |

The files are redistributed for reproducibility. Please follow the licenses of the original sources.

`electricity` and `traffic` are stored as `.csv.gz`; run

    python dataset/prepare_data.py

to create the `.csv` files the launchers expect.

`prepare_eac_streams.py` rebuilds Air-Stream and Energy-Stream from the EAC release
(`python prepare_eac_streams.py download|build air|energy|all`).

SCA-Stream-v2: each `seed_XX.npz` holds `values` (16,384 x 20), the warm-up end, the eight regimes
and their oracle actions (`oracle_actions`). `sca_stream_v2_csv/sca_stream_v2_seedXX.csv` is the same
`values` array as plain CSV for the generic runner. Under the 20/5/75 split with eight online blocks the
block boundaries coincide with the regimes, so block k has oracle action `oracle_actions[k]`.
